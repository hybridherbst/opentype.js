# External Font Validators

The validation runners in this directory exercise fonts generated by
opentype.js against external tools. They are PR-safe: source code and wiring are
checked in, generated outputs go to `test-output/validators`, and large binaries
stay out of git.

Command:

```sh
npm run test:validate
npm run test:validate -- --tool fonttools
npm run test:validate -- --tool fonttools,ots
```

Tool resolution:

- `FONTTOOLS_PYTHON`, then `python3` for FontTools.
- `FONTSPECTOR_BIN`, then `test/validators/bin/fontspector`, then `fontspector`
  on `PATH`.
- `OTS_SANITIZE_BIN`, then `test/validators/bin/ots/ots-sanitize`, then
  `ots-sanitize` on `PATH`.

All validators run by default. Use `--tool` to run a subset; accepted tool names
are `fonttools`, `fontspector`, and `ots`. Missing validators are hard failures
for the explicit validation command. That keeps CI honest when a validation job
opts in, while the normal `npm test` suite remains self-contained.
